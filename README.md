### Пример кода

Базовый ввод/вывод и вычисления

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите ваше имя: ");
        string name = Console.ReadLine();

        Console.WriteLine($"Привет, {name}!");

        int a = 10;
        int b = 3;
        int intResult = a / b;
        Console.WriteLine($"Целочисленное деление: {a} / {b} = {intResult}");
    
        double doubleResult = (double)a / b;
        Console.WriteLine($"Дробное деление: {a} / {b} = {doubleResult}");
        
        double absValue = Math.Abs(-5.7);
        double powValue = Math.Pow(2, 8);
        Console.WriteLine($"Math.Abs(-5.7) = {absValue}");
        Console.WriteLine($"Math.Pow(2, 8) = {powValue}");
    }
}
```
### Выводы

1. В C# нужно сразу объявлять переменные, что помогает избежать ошибок на этапе компиляции. В отличие от Python, C# не позволяет неявно смешивать типы без предварительного приведения

2. Различие между Console.Write() и Console.WriteLine() критично для форматирования вывода. Первый метод оставляет курсор на той же строке, второй — переводит его на новую, что необходимо учитывать при построении интерактивных консольных приложений

3. Платформа .NET обеспечивает двухэтапную компиляцию: исходный код C# преобразуется в промежуточный язык IL, который потом компилируется в машинный код средой CLR

### Ответы на вопросы

1. Чем Console.Write() отличается от Console.WriteLine()?

Метод Console.Write() выводит текст в консоль без перевода курсора на новую строку. Весь последующий вывод продолжается на той же строке.
Метод Console.WriteLine() выводит текст и добавляет символ перевода строки в конце, перемещая курсор на следующую строку. Это различие важно при создании приглашений для ввода (Console.Write("Введите число: ")) и форматировании многострочного вывода

2. Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?

Произойдёт ошибка компиляции. Тип int может хранить только целые числа, а 3.14 — это литерал типа double. C# не выполняет неявное преобразование из double в int, поскольку это привело бы к потере данных (дробной части). Для присваивания потребуется явное приведение: int x = (int)3.14; — в этом случае переменная получит значение 3

3. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?

Операция деления / в C# ведёт себя по-разному в зависимости от типов операндов. Если оба операнда — целые числа, выполняется целочисленное деление, при котором дробная часть отбрасывается. Результат 10 / 3 равен 3, так как 3 помещается в 10 три раза полностью.

Для получения дробного результата необходимо привести хотя бы один из операндов к типу с плавающей точкой, или использовать литерал с плавающей точкой

4. Что означает var в C#? Чем он отличается от динамической типизации в Python?

var в C# — это неявная типизация с выводом типа на этапе компиляции. Компилятор сам определяет тип переменной на основе присваиваемого значения, но после этого тип фиксируется и не может быть изменён.
